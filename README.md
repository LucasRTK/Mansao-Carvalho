# Mansão-Carvalho

# Sobre o jogo
Na virada do século XX, a aristocracia ainda dança sob máscaras… e segredos.

Convidado para o tradicional Baile de Máscaras da família Carvalho, um investigador é chamado discretamente para impedir o pior. A carta é clara: um assassinato ocorrerá naquela noite.
O culpado estará entre os convidados. Ou melhor… entre a própria família.

Em Mansão Carvalho, você explora um jogo point and click de investigação. Máscaras especiais revelam diferentes camadas da realidade: números ocultos, palavras disfarçadas, símbolos que só existem no escuro.

A verdade exige atenção.

Observe os quadros.
Leia o ambiente.
Troque de máscara.
Apague a luz.

Alguns segredos só se revelam quando ninguém está olhando.
